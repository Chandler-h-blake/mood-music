# QQ 音乐 Chrome 连接器

当前迭代实现 Manifest V3 扩展骨架、QQ 音乐标签页发现、只读页面能力探测，以及与本机 API 的协议/能力协商。它不会点击页面、读取 Cookie 或控制播放；队列执行将在页面探测结果经过真实版本验证后接入。

## 本地加载

1. 确保 MoodMusic API 在 `127.0.0.1:8000` 运行。
2. Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开并登录 `https://y.qq.com/`；如果该页面在安装扩展前已经打开，请刷新一次。
5. 点击工具栏中的 MoodMusic 扩展。
6. 点击“检测当前 QQ 音乐页面”。

探测器只输出控件数量与能力代码，不保存页面文字、Cookie、歌曲内容或 HTML。
