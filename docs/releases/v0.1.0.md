# MoodMusic v0.1.0

The first public preview closes the local flow from a user's liked library to an AI-selected, editable queue controlled through the QQ Music desktop client.

## Highlights

- Read-only paginated QQ Music liked-library synchronization with deduplication and recovery.
- DeepSeek-based multi-angle profiles and local BGE-M3 semantic embeddings.
- Natural-language intent parsing, full-library balanced matching, and valid empty results.
- Match, emotion-curve, random, similarity, manual, refinement, and history-restored queues.
- Local playback queue handoff plus play, pause, previous, and next controls.
- Windows-protected storage for QQ Music cookies and model credentials.
- A no-credentials interactive demo for evaluating the product safely.

## Quick try

```powershell
.\scripts\setup.ps1 -DemoOnly
.\scripts\start.ps1 -Demo
```

Open `http://127.0.0.1:5173`.

## Known limitations

- The complete integration targets a single Windows user and the QQ Music desktop client.
- QQ Music private endpoints can change and are isolated behind a replaceable read-only adapter.
- First-time model setup can download large local embedding dependencies and model files.
- The Chrome playback extension remains a compatibility placeholder; desktop playback is the supported route.
- External-song recommendations are not part of this preview.

## Safety and privacy

Do not place real cookies, API keys, personal library exports, or unsanitized logs in GitHub issues. MoodMusic does not bundle QQ Music assets or audio and does not bypass membership, region, copyright, or DRM restrictions.
