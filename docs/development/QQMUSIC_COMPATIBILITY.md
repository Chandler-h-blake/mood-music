当前接口假设：

- 请求入口：`POST https://u.y.qq.com/cgi-bin/musicu.fcg`。
- 模块与方法：`music.srfDissInfo.DissInfo / CgiGetDiss`。
- “我喜欢”目录参数：`disstid=0`、`dirid=201`。
- 诊断预览默认读取第 0 页 30 首；完整同步以每页 100 首顺序读取至平台报告总数。
- 完整同步要求抓取条数与平台报告总数一致；总数中途变化、重复整页或短缺都会终止，最近一次成功曲库保持不变。
- 相同平台歌曲 ID 在入库前去重；平台 ID 缺失的历史/下架条目使用不包含明文元数据的稳定哈希作为本地回退 ID。

这些参数属于当前验证过的内部接口事实，不是腾讯公开稳定合约。任何响应 schema、认证或请求参数变化都必须更新适配器、匿名契约样本和本记录。
