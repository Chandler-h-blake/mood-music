# QQ 音乐兼容性记录

本文件只记录去敏后的兼容性事实。禁止写入 Cookie、QQ 号、真实歌单内容、访问令牌、刷新令牌或第三方原始响应。

## 2026-09-10 首个纵向切片

环境：

- Windows 单用户本机运行。
- QQ 音乐网页版正常登录后，由用户手动复制 Cookie。
- FastAPI 只监听 `127.0.0.1`。
- Cookie 通过 Windows DPAPI 加密，开发环境密文位于 Git 忽略的 `data/credentials`。

验证结果：

| 检查 | 结果 |
| --- | --- |
| Cookie 格式校验 | 通过 |
| 长 Cookie DPAPI 加密保存 | 通过 |
| 保存响应不回显 Cookie | 通过 |
| QQ 音乐登录状态验证 | 通过 |
| “我喜欢”第一页只读请求 | 通过 |
| 歌曲总数与第一页歌曲映射 | 接口正常返回，未在仓库记录真实数据 |
| Cookie 清除能力 | 自动化测试通过 |

当前接口假设：

- 请求入口：`POST https://u.y.qq.com/cgi-bin/musicu.fcg`。
- 模块与方法：`music.srfDissInfo.DissInfo / CgiGetDiss`。
- “我喜欢”目录参数：`disstid=0`、`dirid=201`。
- 首个切片只请求第 0 页，默认 30 首、最大 100 首。

这些参数属于当前验证过的内部接口事实，不是腾讯公开稳定合约。任何响应 schema、认证或请求参数变化都必须更新适配器、匿名契约样本和本记录。
